# Коммерческое предложение · Факторинговое обслуживание

Премиальный комплект коммерческого предложения «РБ Факторинг · Группа Т-Банк»
для рассылки клиентам. Логотипы партнёров сохранены, дизайн рассчитан под
требования корпоративного документооборота: формат **A4**, печатное качество,
русская и английская версии, тарифная сетка под разные лимиты.

Есть **два способа** работать с предложением — выбирайте удобный.

---

## 1. Word-шаблон (заполняете руками → сохраняете в PDF)

> Это самый простой путь, если вы хотите править текст прямо в Word.

| Файл | Назначение |
|------|------------|
| `output/Коммерческое-предложение-RU.docx` | **Русская версия** — открыть в Word, вписать данные. |
| `output/Коммерческое-предложение-EN.docx` | **Английская версия** для международных контрагентов. |

**Как пользоваться:**
1. Откройте `.docx` в Microsoft Word (или LibreOffice / Google Docs).
2. Замените данные под конкретного клиента (см. список полей ниже).
3. Сохраните в PDF: **Файл → Сохранить как / Экспорт → PDF**.

**Что меняется под клиента** (просто кликаете в тексте и правите):
- Название клиента (поставщика) — на обложке, в письме, в таблице условий, в блоке контактов;
- Дебиторы; дата и номер документа;
- Параметры сделки: финансирование %, отсрочка, комиссии, лимит, тип факторинга;
- ФИО менеджера, телефон, e-mail.

Пересобрать Word-файлы из кода (если правили `build_docx.py`):
```bash
python3 build_docx.py            # RU и EN
python3 build_docx.py --lang ru  # только RU
```

## 2. Автогенерация из CSV (предложение под каждого клиента одной командой)

> Путь для потоковой рассылки: данные клиентов в таблице — на выходе готовые
> HTML и PDF, пиксель-в-пиксель, со встроенными шрифтами и логотипом.

1. Впишите клиентов в `clients.csv` (одна строка — один клиент).
   Колонка `langs` задаёт языки: `ru`, `en` или `ru,en`.
2. Запустите генерацию:
```bash
python3 generate.py            # -> output/<клиент>__<язык>.html
python3 generate.py --pdf      # то же + PDF (нужен Node.js + Playwright/Chromium)
python3 generate.py --langs en # принудительно один язык для всех
```
Каждому клиенту автоматически подсвечивается его уровень в тарифной сетке
(по размеру лимита).

Если PDF собирать негде — откройте полученный `output/*.html` в браузере и
**Печать → Сохранить как PDF** (поля: «Нет», фон: включить).

## Структура предложения (6 страниц)

1. **Обложка** — заголовок, ключевые цифры, реквизиты.
2. **Сопроводительное письмо** — обращение и подпись менеджера.
3. **Ценность для бизнеса** — 6 преимуществ + метрики.
4. **Условия сотрудничества** — таблица параметров сделки + сноски.
5. **Тарифная сетка** — ставки под разные объёмы лимита (с подсветкой уровня клиента).
6. **Старт сотрудничества** — 5 шагов запуска, контакты, дисклеймер.

## Состав каталога

```
offer/
├─ output/                     ← готовые файлы (DOCX, HTML, PDF)
├─ assets/
│  ├─ styles.css               ← дизайн-система (HTML-версия)
│  ├─ fonts_embedded.css       ← встроенные шрифты Montserrat + Inter (кириллица)
│  └─ logo.png                 ← логотип-локап T-Bank × Partner
├─ build_docx.py               ← сборка Word-шаблонов (способ 1)
├─ generate.py                 ← генерация из CSV (способ 2)
├─ clients.csv                 ← данные клиентов
├─ render-pdf.mjs              ← HTML → PDF (Chromium)
└─ README.md
```

## Брендинг

- Жёлтый Т-Банк `#FFDD2D`, графит `#16161A`, бронзовый акцент `#B0895A`.
- HTML-версия: шрифты **Montserrat** (заголовки) + **Inter** (текст), кириллица встроена.
- Word-версия: **Georgia** (заголовки) + **Calibri** (текст) — есть в любом Office.
- Логотип сохранён без изменений.
