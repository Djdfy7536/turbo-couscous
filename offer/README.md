# Коммерческое предложение · Факторинговое обслуживание

Премиальный шаблон коммерческого предложения «РБ Факторинг · Группа Т-Банк»
для рассылки клиентам. Логотипы партнёров сохранены, дизайн адаптирован под
требования корпоративного документооборота: формат **A4**, печатное качество,
самодостаточный файл (шрифты и логотип встроены — работает офлайн и одинаково
отображается на любом устройстве).

## Готовые файлы

| Файл | Назначение |
|------|------------|
| `Коммерческое-предложение-Факторинг.pdf` | **Готовый документ для отправки клиенту.** |
| `Коммерческое-предложение-Факторинг.html` | Самодостаточная веб-версия (открывается в любом браузере, можно печатать в PDF через Ctrl+P). |
| `offer.template.html` | Редактируемый исходник (текст и вёрстка). |

## Структура (5 страниц)

1. **Обложка** — заголовок, ключевые цифры, реквизиты предложения.
2. **Сопроводительное письмо** — обращение и подпись менеджера.
3. **Ценность для бизнеса** — 6 преимуществ + ключевые метрики.
4. **Условия сотрудничества** — таблица параметров сделки + сноски.
5. **Старт сотрудничества** — 5 шагов запуска, призыв к действию, дисклеймер.

## Как адаптировать под другого клиента

Все изменяемые данные находятся в `offer.template.html`. Отредактируйте текст
прямо в файле (поиском по значению), затем пересоберите документ:

Что обычно меняется:
- **Клиент / поставщик** — `ООО «КОНКОРД»` (встречается на стр. 1, 2, 4, 5);
- **Дебиторы** — `ООО «ВСЕИНСТРУМЕНТЫ.РУ»` (стр. 4);
- **Дата и номер** — `09 июня 2026`, `КП-2026/06-09` (стр. 1);
- **Условия** — финансирование, отсрочка, комиссии (стр. 4, блок `.terms`);
- **Менеджер** — ФИО, телефон, e-mail (стр. 2 и 5).

## Пересборка

```bash
# 1. Собрать самодостаточный HTML (внедряет шрифты + логотип)
python3 build.py

# 2. Отрендерить PDF (нужен Node.js + Playwright/Chromium)
PLAYWRIGHT_PKG=$(npm root -g)/playwright node render-pdf.mjs
```

Если PDF собирать негде — откройте `…Факторинг.html` в браузере и
**Печать → Сохранить как PDF** (поля: «Нет», фон: включить).
